# בוחן הבחירות הגדול

משחק טריוויה לבחירות לכנסת ה־26 (27 באוקטובר 2026): מתאימים נקודות מצע לפתק המפלגה הנכון, ובסוף מקבלים את המפלגות שהכי קרובות לעמדות שלכם. בכל משחק מוגרלות 12 שאלות מתוך מאגר של 36, שאלה אחת לכל מפלגה, כך שכל המפלגות מקבלות משקל זהה. אחרי שלושה משחקים רואים את כל המאגר.

כל המשחק הוא קובץ אחד, `index.html`, בלי תלויות חיצוניות. הוא עובד גם בלי אינטרנט וגם בתצוגה מקדימה שחוסמת סקריפטים.

תמונות ראשי המפלגות מוויקישיתוף, ברישיונות חופשיים; הקרדיטים בתחתית המשחק. אפקט ההטיה: vanilla-tilt.js (MIT). המשחק אינו מביע תמיכה באף מפלגה.
